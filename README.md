# ADEGA SINTONIA - SISTEMA DE GESTÃO COMPLETO PARA ADEGAS Um sistema de gestão completo e fácil de usar, ideal para adegas de todos os portes. Gerencie seu estoque, vendas presenciais (comanda) e pedidos via WhatsApp em um só lugar. ## Funcionalidades Principais * **Gestão de Estoque:** * Controle total do seu estoque de bebidas e produtos. * Alertas de estoque baixo para evitar falta de produtos. * **Vendas Diretas e Comandas:** * Interface intuitiva para vendas no balcão. * Sistema de comandas para clientes que consomem no local. * **Pedidos via WhatsApp:** * Integração com WhatsApp para receber e gerenciar pedidos online. * Automatização de respostas e envio de informações para os clientes. * **Relatórios e Análise:** * Geração de relatórios de vendas, estoque e fluxo de caixa. * Análise de dados para tomada de decisões estratégicas. * **Banco de Dados SQLite:** * Utiliza SQLite, um banco de dados leve e fácil de configurar, ideal para uso local. ## Como Começar 1. **Download:** * Faça o download do arquivo .zip do sistema. 2. **Extração:** * Extraia o conteúdo do arquivo .zip para uma pasta de sua preferência (exemplo: `C:\Adega`). 3. **Execução:** * Execute o arquivo `IniciarSistema.bat`. * O sistema será aberto automaticamente no seu navegador no endereço `http://localhost:5198/Combo/Index`. 4. **Login Padrão:** * Usuário: `admin` * Senha: `1234` ## Configuração Adicional (WhatsApp) * Certifique-se de ter o Node.js instalado em sua máquina. * Configure as variáveis de ambiente necessárias para a comunicação com o WhatsApp (mais detalhes na documentação interna do projeto). ## Iniciando o Sistema Automaticamente com o Windows 1. Crie um atalho do arquivo `IniciarSistema.bat`: * Clique com o botão direito sobre o arquivo > Enviar para > Área de trabalho (criar atalho). 2. Pressione as teclas `Win + R` e digite: `shell:startup` 3. Na pasta que será aberta, cole o atalho criado. **Importante:** Esse processo fará com que o sistema seja iniciado automaticamente após o login do Windows. O sistema abrirá minimizado por causa do comando `start /min` usado no arquivo `.bat`. ## Atenção * Não exclua ou mova as pastas `Data` ou `wwwroot`. * O arquivo `adega.db`, localizado dentro da pasta `Data`, é o banco de dados local do sistema. * Esta versão está em modo de testes e tem validade de 30 dias. ## Estrutura dos Arquivos * `Adega.exe`: Arquivo executável do sistema. * `Data/adega.db`: Banco de dados do sistema. * `wwwroot/`: Imagens e arquivos estáticos. * `IniciarSistema.bat`: Arquivo para iniciar o sistema de forma prática. ## Suporte Em caso de dúvidas, entre em contato: * E-mail: joaorogodoy@gmail.com * Telefone: (11) 97132-9882.
